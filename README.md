## 📌 Historical Overview

This repository preserves the historical native Android application for customers originally developed for the Alfa and Omega Logistics Fleet Dispatch Platform. It featured pickup/delivery point pinning on Google Maps and automated distance fare estimation.

All components, database schemas, and workflows have been merged and modernized into the primary repository: **[android-logistics-fleet-dispatch-platform](https://github.com/KevinAndrey96/android-logistics-fleet-dispatch-platform)**.
